PBN Commander Client WordPress Plugin

Download & Install Official Client Plugin

Install this plugin on each child WordPress website to enable secure encrypted HMAC communication, automated article publishing, and sidebar link widget control.

Download Plugin ZIP

Installation Steps:

  1. Download the pbn-commander-client.zip file using the button above.
  2. Log in to your WordPress admin dashboard (e.g. https://yourchildsite.com/wp-admin).
  3. Go to Plugins → Add New → Upload Plugin and upload the ZIP file.
  4. Activate the PBN Commander Client plugin.
  5. Navigate to PBN Commander in your WordPress sidebar.
  6. Copy the unique Site API Key generated for your domain from this dashboard and paste it into the plugin settings page.

Application Configuration

Configured via environment variable JWT_SECRET.
