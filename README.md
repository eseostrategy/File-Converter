# Eseo Strategy Website

This repository hosts the static website for **Eseo Strategy**, a digital services agency specializing in SEO, content marketing, and link building for the casino, betting, and affiliate marketing niches.

## Design System
- **Theme**: Modern Dark
- **Background**: `#0B0F19`
- **Primary Color**: `#3B82F6` (Blue)
- **Accent Color**: `#8B5CF6` (Purple)
- **Typography**: Segoe UI

## Structure
- `index.html`: Home page
- `services.html`: Services overview
- `about.html`: About the agency
- `contact.html`: Contact information
- `styles.css`: Global styles
- `script.js`: Interactive elements
