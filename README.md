# ESEO Strategy - Pricing Page

A modern, responsive landing page for an SEO Agency featuring service highlights and detailed pricing plans.

## Features
- **Dark/Light Mode Toggle**: Built-in support for theme switching via CSS variables and `localStorage`.
- **Responsive Layout**: Utilizing CSS Grid and Flexbox for mobile-first design.
- **Service Categories**: Extensive list of SEO services including Monthly Packages, PBN Backlinks, SEO Backlinks, Guest Posts, and more.

## Tech Stack
- HTML5
- CSS3 (Variables, Flexbox, Grid)
- Vanilla JavaScript
- FontAwesome Icons

## Running Locally
Since it is a static site, simply open `index.html` in any modern browser to view the page.
